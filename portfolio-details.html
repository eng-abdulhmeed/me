greeting-cards.premiumasp.net Live Card Editor GitHub Profile

TomNum — Telegram Digital Services Platform

@TomNumbot github.com/.../telegram-bot

منصة خدمات رقمية متطورة مبنية على تليجرام لإدارة وبيع أرقام التفعيل الافتراضية، تدعم مسارات محادثة متسلسلة متعددة الخطوات (Multi-Step Conversational Workflows) مع دعم واجهات متعددة اللغات.

تم تنفيذ نماذج بيانات PostgreSQL متقدمة مع إدارة حالات الجلسات بواسطة آلة الحالة المحدودة (Redis-backed Finite State Machine - FSM)، مع دمج واجهات البرمجة الخارجية (REST APIs) والخطافات البرمجية (Webhooks)، بالإضافة إلى حزم التطبيق داخل حاويات Docker ونشرها سحابياً على منصة Railway.

  • PostgreSQL & Redis FSM: هيكلة نماذج بيانات عالية الاعتمادية وإدارة مرنة لجلسات المستخدمين المتزامنة بدون فقدان للبيانات.
  • APIs, Webhooks & Payments: تكامل آلي كامل مع واجهات تزويد الأرقام وبوابات الدفع الرقمية والعملات المشفرة Cryptomus.
  • Dockerized Cloud Deployment: حزم التطبيق عبر Docker ونشره على Railway لضمان أداء مستمر وجهوزية تشغيل على مدار الساعة.

Nawwar — نوار | Knowledge-Based Social Platform

Desktop Client (C# .NET) GitHub Repository

منصة اجتماعية معرفية متكاملة مصممة بنمط اقتصاد المعرفة (Value-Driven Knowledge Economy)، تهدف إلى تنظيم ومشاركة المعرفة العلمية عبر منهجية هندسية صارمة تشمل تحليل النظم الكامل وتصميم التجربة والتطوير المكتبي.

شمل المشروع دراسة وتحليل متطلبات المنتج وتوثيق المواصفات الوظيفية (SRS)، تدفقات المستخدمين (User Flows)، وهيكلية المعلومات (Information Architecture)، وتصميم واجهات تفاعلية ونماذج أولية قابلة للاختبار عبر Figma وFigJam، إلى جانب بناء العميل المكتبي متعدد النماذج بـ C# وهندسة كائنية التوجه (OOP).

  • System Analysis & SRS: توثيق دقيق للمتطلبات الوظيفية وتفاعلات الإنسان والحاسوب (HCI) وتدفقات العمليات.
  • Figma & FigJam Prototyping: تصميم Wireframes ومكونات واجهة مستخدم قابلة لإعادة الاستخدام مع نماذج تفاعلية من خلال عملية بحث وتجربة واضحة.
  • Multi-Form C# Desktop Client: تطبيق مكتبي متكامل بهيكلية تنقل منظمة، معمارية كائنية التوجه، وتكامل كامل مع قواعد البيانات.

Multi-Tab Browser | مستكشف التبويبات المتعددة

C# WinForms TabControl GitHub Profile

تطبيق متصفح ويب مكتبي متكامل مبني بلغة C# وأنظمة Windows Forms، يتميز بنظام إدارة تبويبات ديناميكي مستقل يتيح فتح عدة جلسات تصفح متزامنة بسلاسة.

تم تصميم المتصفح ليوفر تجربة تصفح سريعة وخفيفة على الذاكرة، مع عناصر تحكم كاملة تشمل شريط عناوين مع أزرار التنقل السريع (انتقال، الرئيسية، تحديث)، وقائمة منسدلة لاختيار التبويبات المفتوحة وحذفها أو إغلاق التبويب الحالي بسهولة.

  • Dynamic TabControl: إنشاء وإغلاق صفحات تصفح مستقلة تماماً داخل أداة TabControl ديناميكية.
  • Quick Navigation Bar: شريط إدخال العناوين المباشرة مع أزرار الانتقال والتحديث وزر العودة للصفحة الرئيسية.
  • Multi-Tab Manager: عداد ذكي للتبويبات المفتوحة مع قائمة لاختيار التبويبات وإدارتها أو حذفها بضغطة زر.
